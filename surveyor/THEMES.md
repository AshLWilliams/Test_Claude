# Level Runner: как устроена тема (участок)

Кампания состоит из 10 участков. Каждый участок — **тема** в файле `surveyor/themes/NN-id.js`.
Движок (`surveyor/engine.js`) отвечает за физику, генерацию уровня, камеру, героя, рейку, счёт, HUD,
меню, переходы между участками, рейтинги и сенсорное управление. Тема отвечает за **вид и обитателей** участка.
Образец — `themes/01-city.js`.

Файл темы — обычный скрипт (без модулей и сборки), обёрнутый в IIFE, который вызывает `registerTheme({...})`.
Не создавайте глобальных переменных, кроме вызова `registerTheme`. Не меняйте `engine.js`.

## Игровые единицы
Кадр 360 единиц по высоте, ширина `api.W` от 560 до 860 (зависит от экрана). Ось Y вниз.
Земля обычно на высоте y ≈ 225…305 (верх земли). Герой — 18×40, прыгает на ~107 вверх и ~150 вперёд.
Все координаты мира — в тех же единицах; камера сдвигает мир на `api.camX` по X.

## Объект темы
```js
registerTheme({
  index: 3, id: 'metro',                    // порядковый номер участка 1..10 и короткий id
  title: 'Метро', subtitle: 'Проходка тоннеля…', // название и подзаголовок (показываются в заставке участка)
  accent: '#7ec8ff',                        // цвет акцентов HUD и заголовков
  dust: '#9a9a9a',                          // цвет пыли от прыжков/приземлений
  headlamp: false,                          // true — на каске героя светится фонарь (для тёмных участков)
  snowy: false,                             // true — снег налипает на героя, шаги хрустят (снежные участки)
  gen: { ... },                             // параметры генератора (см. ниже), можно {}
  decor: ['lamp', 'sign'],                  // виды декора (повтор = чаще); рисует drawDecor
  enemies: { ... },                         // враги (см. ниже)
  enemyTable: [ ... ],                      // где и как часто появляются враги
  init(api) {},                             // необязательно: при загрузке участка (сбросить состояние темы)
  update(dt, api) {},                       // необязательно: каждый шаг физики в режиме игры (ветер, обвалы, метель)
  drawBackground(ctx, api) {},              // ОБЯЗАТЕЛЬНО: весь экран за миром, экранные координаты (параллакс сами через api.camX)
  drawGround(s, ctx, api) {},               // ОБЯЗАТЕЛЬНО: грунт {x,y,w,h}; рисуйте от s.y до низа экрана (s.x-0.5, ширина s.w+1 — без щелей)
  drawPit(p, ctx, api) {},                  // ОБЯЗАТЕЛЬНО: провал {x,y,w,v} (y — уровень земли перед провалом), рисуйте от p.y вниз
  drawPlatform(p, ctx, api) {},             // ОБЯЗАТЕЛЬНО: проходимая снизу платформа {x,y,w,h:10,base,tier,v}; base — y опоры (земля или нижний ярус)
  drawObstacle(s, ctx, api) {},             // ОБЯЗАТЕЛЬНО: твёрдый блок-препятствие {x,y,w,h,stack,v}, стопка из stack блоков высотой gen.obstacleH
  drawDecor(d, ctx, api) {},                // ОБЯЗАТЕЛЬНО, если есть decor: {kind,x,y,v}, y — уровень земли, рисуйте вверх от y
  drawFinish(fx, gy, ctx, api) {},          // постройка у финиша: флаг в fx рисует движок, ваша постройка — правее (fx+120…fx+400)
  drawForeground(ctx, api) {},              // необязательно: слой в координатах мира поверх героя (капли, пар)
  drawOverlay(ctx, api) {},                 // необязательно: слой в экранных координатах поверх мира (темнота, метель, туман)
});
```
`v` у провалов/платформ/препятствий/декора — случайное число 0…1 для разнообразия (стабильно для объекта).
Все функции рисования вызываются внутри `ctx.save()/restore()` — меняйте стили свободно. `ctx` уже в координатах
мира (кроме `drawBackground` и `drawOverlay`, где экранные координаты 0…W × 0…360).

### gen — параметры генератора (все необязательны)
| поле | по умолчанию | смысл |
|---|---|---|
| `length` | 3800 | базовая длина участка; движок умножает её на 1.6 (участки длинные, ~30 с бега) |
| `weights` | `{pit:24, platforms:20, step:14, obstacle:14, flat:28, wall:9, tower:8}` | частоты отрезков: провал, платформы в 2 яруса, перепад высот, препятствие, ровный, **стена** (выше прыжка, подъём по лестнице), **вышка** (3 яруса по лестницам, верх — выше края экрана) |
| `pitW` | `[70,112]` | ширина провалов (движок ограничит ≤112 — это предел прыжка) |
| `groundRange` | `[225,305]` | диапазон высоты земли |
| `upperChance` | 0.7 | вероятность второго яруса платформ |
| `enemyDensity` | 1 | множитель плотности врагов (0.6…1.4) |
| `hazardChance` | 0.35 | вероятность статичной опасности на ровном отрезке (если в enemyTable есть `where:'hazard'`) |
| `obstacleH`, `obstacleW` | 30, 44 | размер блока препятствия (20…32 × 30…60) |
| `decorCount` | `[0,2]` | сколько декора на отрезок |
| `friction` | 1 | <1 — скользко (лёд), не ниже 0.5 |
| `boss` | null | только для финального участка: `{ type: 'имя врага-босса', arenaW: 860 }` |

Движок гарантирует проходимость: провалы ≤ 112, перепады ≤ 55, после препятствий есть разбег.

## Враги
```js
enemies: {
  rat: {
    w: 26, h: 14, hp: 1, pts: 100,       // размер (хитбокс), здоровье в ударах, очки
    flip: true,                          // (по умолч.) рисунок отражается по e.dir — рисуйте врага «смотрящим вправо»
    heavy: false,                        // тяжёлый: слабее отбрасывается, сильнее трясёт экран при гибели
    stompable: true,                     // можно ли победить прыжком сверху
    invulnerable: false,                 // неуязвим (для опасностей вроде лужи битума)
    contact: true,                       // проверять ли касание с героем (false — ни урона, ни прыжка сверху)
    touchHurts: true,                    // false — касание не ранит, но прыжок сверху засчитывается (враг бьёт сам, как халтурщик с GPS)
    knockback: true,                     // отбрасывается ли ударом рейки
    hitColor, deathColor,                // цвета искр при попадании/гибели
    init(e, api) {},                     // после появления: e.minX/maxX, e.groundY, e.air уже заданы
    update(e, dt, api) {},               // поведение; двигайте e.x/e.y сами (api.patrol помогает)
    draw(e, ctx, api) {},                // начало координат — СЕРЕДИНА НИЗА хитбокса; вверх — отрицательный y
    hurtbox(e, api) { return {x,y,w,h}; }, // необязательно: куда попадает рейка (по умолч. сам e)
    bodybox(e, api) { return {x,y,w,h}; }, // необязательно: чем враг ранит героя (по умолч. сам e)
    onHit(e, api, source) {},            // необязательно: вернуть false — удар не засчитан (броня); source: 'staff'|'stomp'|'projectile'
    onDeath(e, api) {},                  // необязательно: при гибели (раскол, взрыв, выпадение)
    // только для босса: boss: true, bossName: 'Имя', bossSub: 'подзаголовок'
  },
}
```
Поля врага `e`: `x, y, w, h` (левый верх хитбокса), `hp, maxHp, dir (±1), t` (время жизни, для анимации),
`hit` (>0 — только что получил удар), `cd` (свободный таймер, стартует случайно 1…2 с), `minX, maxX` (границы его
отрезка земли — не выходите за них, иначе враг «повиснет» над провалом), `groundY` (верх земли/платформы под ним),
`air` (появился в воздухе), `awake` (был в кадре). Можно добавлять свои поля.
Враги обновляются, только когда оказались рядом с кадром (`awake`), — не нужно проверять это самим.

### enemyTable — где появляются
```js
enemyTable: [
  { type: 'rat',   where: 'ground', weight: 3 },            // на земле (ходит в пределах отрезка)
  { type: 'bat',   where: 'air', weight: 2, from: 0.2 },    // в воздухе: появится на ~110–150 выше земли
  { type: 'welder', where: 'upper', weight: 1 },            // на втором ярусе платформ (стоит/ходит по нему)
  { type: 'puddle', where: 'hazard', weight: 1 },           // статичная опасность посреди ровного отрезка (ширина ≤ 64)
]
```
`from`/`to` — доля пройденного участка (0…1), с которой/до которой тип встречается.
Опасности `hazard` должны быть `invulnerable: true, stompable: false` и перепрыгиваемыми (ширина ≤ 64, высота ≤ 40).

## api — что доступно теме
Свойства: `W, H, camX, player` ({x,y,w,h,vx,vy,face,onGround,inv}), `time` (с начала участка), `now` (секунды, для анимации),
`enemies, solids, platforms, pits, projectiles, levelIndex, levels, progress (0…1), arena, mode`.
Функции:
- `rand(a,b)`, `clamp(v,a,b)`, `hash(n)` (детерминированный 0…1 — для параллакса и узоров), `overlap(a,b)`
- `text(str, x, y, size, color, align)`, `drawStaff(len)` — рисует нивелирную рейку
- `patrol(e, speed, dt)` — ходьба с разворотом у границ отрезка; `dx(e)` — расстояние до героя по X (>0 — справа); `near(e, rx=240, ry=120)`
- `spawnEnemy(type, x, groundY, props)` — призвать врага своей темы (x — центр, groundY — на чём стоит)
- `shoot({x, y, w, h, vx, vy, gravity=900, life=6, spin, color, draw(p,ctx,api), reflectable, destructible=true, hitsSolids=true, hurts=true, pts=10, source, onLand(p,api), update(p,dt,api), silent})` — на экране звучит свист (silent: true — без него)
  — снаряд (x, y — центр). Рейка разбивает `destructible` снаряды (+очки) и **отбивает** `reflectable` во врага `source`
  (отбитый снаряд наносит урон врагам). `draw` рисует вокруг (0,0), поворот `rot` учтён.
- `hurtPlayer(fromX)` — ранить героя (есть неуязвимость после урона), `damageEnemy(e, n, source)`
- `burst(x, y, color, n, speed, grav)` — искры/обломки, `popup(x, y, text, color)`, `addScore(n, x, y)`, `shake(n)`
- `groundAt(x)` — верх твёрдой земли в точке x или `null` над провалом; `toScreen(x, y)` — мир → экран

## Правила качества
- **Проходимость — главное.** Механики темы (ветер, лёд, обвалы) не должны делать уровень непроходимым: всё,
  что падает сверху, предупреждается ≥ 0,8 с (тень/пыль/мигание); ветер не сталкивает в провал в прыжке.
- **Честные враги:** угроза читается заранее; неубиваемых обычных врагов нет (кроме опасностей-hazard).
- **Производительность (телефоны):** фон рисуйте только видимую часть (циклы по `Math.floor(off/step)`), без
  `shadowBlur` в циклах, без `getImageData`, градиенты создавайте экономно. Кадр ≤ ~2 мс в стенде.
- **Стиль:** плоская векторная графика как в `01-city.js`, 3–4 слоя параллакса, узнаваемые силуэты,
  палитра под тему, подписи — по-русски. Враги смотрят вправо в `draw` (движок отражает).
- Тексты и комментарии — на русском, в стиле `01-city.js`.

```

```
Стенд печатает отчёт (ошибки, проходимость, враги, время кадра) и сохраняет скриншоты в `--out`
(`*-p15/p45/p75.png`, `*-lineup.png` — все враги в ряд, `*-finish.png`). Смотрите скриншоты глазами.
Для игры в браузере: `surveyor/index.html?level=N` — тренировка с участка N (подключите тему в index.html).

## Вертикаль: стены, вышки, лестницы, камера
- **Стена** — отрезок земли `{kind:'ground', wall:true}` на 130–150 выше соседей; слева к ней приставлена лестница
  (`ladders`, у неё `wall:true`). Рисуйте её в `drawGround` по флагу `s.wall` в духе участка (дом, контейнеры, скала,
  бетонный блок, ледяной торос…), верх — «пол», по которому ходят.
- **Вышка** — три проходимых снизу платформы `tier: 1..3` (`p.tower === true`) на 110/230/350 выше земли, между ярусами —
  лестницы. `drawPlatform` рисует опоры от `p.y` до `p.base` — для вышки это высокие конструкции (леса, фермы, крепь…).
  На верхних ярусах бывают враги `where:'upper'` и каски.
- **Лестница** `{x, w:22, top, bottom, wall, v}` — движок рисует стальную лестницу; тема может нарисовать свою: `drawLadder(l, ctx, api)`
  (координаты мира; от `top-14` до `bottom`).
- **Камера** поднимается, когда герой высоко: `api.camY ≤ 0`. Мир (все draw*, кроме фона и overlay) уже сдвинут движком.
  `drawBackground` движок рисует со сдвигом вниз на `−camY·0.35` и заливает открывшуюся полосу цветом верхнего края фона —
  делайте верх фона однотонным/градиентом. В `drawOverlay` (экранные координаты) переводите мир в экран через `api.toScreen(x, y)`
  или вычитайте `api.camX` и `api.camY`.
- **Урон от падения:** падение больше 260 по высоте отнимает каску (спрыгнуть со стены безопасно, с верха вышки — больно).
- **Каски** (белая +2 жизни, оранжевая +1) расставляет и рисует движок — на вершинах вышек и изредка на стенах.

## Что движок добавляет сам (темы ничего не делают)
- **Разрушаемые предметы** (`solids` с `kind: 'breakable'`, виды — `BREAKABLES`) на ровных отрезках, уступах и настилах; набор участка — `gen.breakables`
  (по умолчанию — `THEME_BREAKABLES[id]`).
- **Подземелье** (`gen.underground: 'metro' | 'mine'`, вес `weights.under`): тоннели `api.tunnels` ({x1, x2, top, slabBot, floor}); над ними —
  перекрытия `slab: true` с дырами. Задник — `drawTunnel(t, ctx, api)` темы или движка. Земля на таких участках рисуется глубже кадра (api.H больше).
- **Здание** (`gen.indoor: true`): этажи `api.rooms` ({x1, x2, y, top}), потолки — `solids` с `kind: 'ceiling'` (не опора: groundAt их пропускает).
  Тема может нарисовать `drawRoom(rm, ctx, api)` и `drawCeiling(s, ctx, api)`.
- **Задний план**: бригады рабочих, птицы, самолёты, крысы — `AMBIENT[id]` в движке.
- **Тайник** в стене: `ghosts` — стена рисуется целиком через `drawGround`, а сталкиваются с ней по кускам (`hidden: true`, `kind: 'hidden'`);
  вход закрыт кладкой с трещинами (`sort: 'crack'`). Внутри — золотые чертежи. Перебирая `api.solids`, учитывайте эти виды.
- **Каски**: наверху вышек и стен, изредка на земле; в бою с боссом вылетают из него (`bossDrop`) и живут 7,5 с.
- **Геодезист-халтурщик с GPS** (`ENGINE_ENEMIES.gps`, варианты — `GPS_VARIANTS[индекс участка]`) — один на участок.
