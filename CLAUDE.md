# CLAUDE.md — заметки для Claude (облачная версия)

## Музыка для игр

Музыку для игр этого репозитория пишет **локальный Claude** — на компьютере пользователя,
моделью ACE-Step 1.5 на его видеокарте (MCP-сервер `music`, проект «Генератор музыки»).
Из облака до неё не дотянуться, поэтому обмен идёт через репозиторий.

### Как заказать трек

1. Допиши строку в `music-requests.md` (корень репозитория): игра; для чего трек
   (участок, меню, босс, событие); id файла; настроение и стиль; темп; желаемая длина
   петли; что важно.
2. Скажи пользователю: «заказал музыку — передай локальному Claude».
3. Сам музыку не сочиняй (синтез в `audio.js` — только для звуковых эффектов) и чужие
   треки из интернета не скачивай.

### Как приходят треки

Локальный Claude присылает их запросом на слияние из ветки `music/…`:

- файлы — в папке музыки игры (Level Runner: `surveyor/music/`), рядом `manifest.json`;
- **каждый трек — готовая бесшовная петля**: файл целиком повторяется без шва
  (`loop_start_s` = 0, `loop_end_s` = длина файла);
- два формата одного звука: `<id>.ogg` (Vorbis) и `<id>.mp3`;
- громкость у всех одинаковая: −16 LUFS, пик не выше −1 dBTP. У прежнего трека
  «КиШ Геодезия» −15,9 LUFS — то же самое, `MUSIC_VOL` менять не нужно;
- `manifest.json` пишет только локальный Claude: список треков — id, назначение
  (`use`: `level` / `menu` / `boss`), номер участка (`level`), файлы, длительность, точки
  петли, темп, такты, громкость, происхождение (`origin`).

### Как подключать (Level Runner)

- В `surveyor/audio.js` бери треки из `music/manifest.json` (загрузить при старте), а не
  вписывай имена файлов в код: следующие треки придут новыми записями манифеста.
- Трек участка — запись с `use: "level"` и `level` = номер участка (1–10, то есть
  `levelIdx + 1`). Нет трека для участка — играет прежний общий `kish-geodeziya.mp3`.
  Запись `use: "menu"` — для меню, `use: "boss"` — для боя с боссом (`arena.active`), если
  решишь их разделять.
- Формат: `.ogg`, если `new Audio().canPlayType('audio/ogg; codecs="vorbis"')` не пустая
  строка, иначе `.mp3` (iOS и Telegram на iOS).
- Повтор: `<audio loop>` годится, но у MP3 на стыке бывает провал 20–50 мс. Бесшовно —
  Web Audio: `decodeAudioData` + `AudioBufferSourceNode` с `loop = true`, `loopStart` и
  `loopEnd` из манифеста.
- Сохрани то, что уже есть: звук только после первого нажатия, на паузе и в свёрнутой
  вкладке — тишина, кнопка звука и клавиша M.

### Формат manifest.json — один на все игры (решение облачной версии, 2026-10-01)

Формат Level Runner: `tracks` — **список** записей `{ id, use, level?, key?, title, files: { ogg, mp3 }, duration_s,
loop_start_s, loop_end_s, bpm, bars, lufs, … }`. `use`: `level` / `menu` / `boss` / `jingle`.
- Level Runner: участок — `use: "level"` + `level` (1–10).
- Топограф (`topograf/music/`): участок — `use: "level"` + `key` = ключ уровня (`"piket/village"`, `"traverse/block"` …);
  меню — `use: "menu"`; джинглы — `use: "jingle"` + `key`: `"clear"` (участок сдан) или `"win"` (смена закрыта).
  Нынешний словарный манифест «Топографа» игра тоже понимает, переделывать его не нужно — новые треки присылай уже списком.

### Как подключено (Топограф)

`topograf/audio.js`: кнопка «♪ файл / ♪ синт» рядом со звуком (по умолчанию — файлы). В режиме файлов — петля уровня через
Web Audio, джинглы вместо синтезированных фанфар; на последних 20 с уровня трек на 6 % быстрее. Нет трека — синтез `music.js`.

### Не делай

- Не перекодируй, не обрезай и не нормализуй присланные файлы — сломается шов.
- Не правь `manifest.json` руками и не удаляй треки без слова пользователя.
