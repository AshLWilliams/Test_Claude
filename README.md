# ★ Star Dodger

Мини-игра на чистом JavaScript + Canvas, без зависимостей.
Управляй кораблём, уворачивайся от астероидов и собирай кристаллы. Сложность растёт со временем.

## Запуск
Откройте `index.html` в браузере (или `python3 -m http.server` и зайдите на `localhost:8000`).

## Управление
- ← → / A D — движение; мышь или касание — корабль летит к курсору
- Пробел — старт / пауза / рестарт

Рекорд сохраняется в `localStorage`.

## Telegram
Игра запускается как Telegram Game. В @BotFather: `/newgame` → короткое имя `stardodger` и URL страницы игры.
Бот (`bot/bot.js`, Node 18+): `BOT_TOKEN=... node bot/bot.js` — отвечает на `/start` и `/play` сообщением с игрой.
Токен бота хранится только в переменной окружения, в репозиторий его не добавляйте.
